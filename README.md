# cameramodule
Open Source self contained camera module for a high performance 3" amateur rocket, specifically amateur spaceshot second stages. 

Integrating a COTS camera, the Runcam Split 4 V2, with a custom LORAWAN enabled control PCB and custom machined mounting/camera shrouding

Engineered to withstand Mach 6+ velocities and operate beyond the Kármán line (100km), the boundary of space
